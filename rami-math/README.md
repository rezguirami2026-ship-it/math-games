# قرية الخير — مغامرة رامي ماث

لعبة رياضيات يتحرك فيها البطل داخل قرية، والرياضيات هي آلية اللعب نفسها.

## البنية
- `core/` المحرك (الحلقة، الكاميرا، اللمس)، الحالة، الأحداث، الصوت
- `save/` الحفظ في الجهاز
- `character/` رسم الشخصية البشرية وحركتها
- `player/` تحريك البطل
- `world/` القرية، العناصر التفاعلية، إيجاد الطريق
- `npc/` أهل القرية
- `story/` الفصول والحوار والأهداف
- `missions/` المهام (القافلة، الزراعة)
- `math/` المنطق الرياضي الصِّرف (بلا رسم)
- `rewards/` نقاط الخير 💚
- `achievements/` الإنجازات
- `ui/` الواجهة البسيطة وشاشات البداية
- `content/lessons.js` خريطة الدروس الـ٦٩ بترتيب المنهج
